# Foodgram Auto Tests Playwright

Переписанные с Selenium на Playwright автотесты для учебного сервиса Foodgram https://foodgram-frontend-1.prakticum-team.ru

## Структура проекта
```
├── tests/ # Тесты 
├── pages/ # Page Object модели 
├── locators/ # Локаторы элементов 
├── helpers/ # Утилиты (генераторы, урлы, константы) 
├── conftest.py # Фикстуры 
└── requirements.txt # Зависимости
```
